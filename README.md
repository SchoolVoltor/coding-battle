# 🛡️ Танкова Арена

Шкільне змагання з програмування в стилі Robocode, яке працює на звичайному смартфоні. Учні програмують танк блоками (як у Scratch) або на Python українською, а потім їхні танки самі б'ються між собою.

- **Майстерня** (`index.html`) — сторінка для учнів: створити танк, натренувати його проти вбудованих ботів і ботів друзів, надіслати вчителю.
- **Арена** (`arena.html`) — сторінка для вчителя: зібрати ботів учнів, показати бій на проекторі, провести кругову систему й плей-оф.

Без сервера, реєстрації та встановлення: усе працює в браузері й зберігається на пристрої.

## Публікація на GitHub Pages

1. Завантажте файли в репозиторій (у корінь).
2. **Settings → Pages → Build and deployment → Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Через хвилину сторінки будуть доступні тут:
   - Майстерня: `https://<логін>.github.io/<репозиторій>/`
   - Арена: `https://<логін>.github.io/<репозиторій>/arena.html`

Посилання на Майстерню зручно перетворити на QR-код для плаката.

> Пошта вчителя для кнопки «✉️ Надіслати вчителю» задається на початку скрипта в `index.html` (`TEACHER_EMAIL`).

## Як учень здає танк

1. Відкриває Майстерню, вводить ім'я, клас і назву танка.
2. Програмує в блоках або на Python, тренується у вкладці «⚔️ Тренування».
3. У вкладці «📤 Здати» натискає «📦 Підготувати бота». Сторінка перевіряє:
   - чи немає помилок у програмі;
   - чи є хоча б одна подія;
   - чи проходить танк **кваліфікацію** — перемагає «Мішень» у 2 з 3 боїв.
4. Надсилає код `TNK…` будь-яким способом: копіювати, «поділитися» в месенджер, e-mail або файл.

Код — це вся програма в одному рядку. Якщо учень змінив танк, він надсилає новий код. В Арені стара версія того самого учня автоматично замінюється новою.

## Як провести турнір (Арена)

1. **Учасники:** вставте в поле всі отримані коди. Можна скопіювати весь чат із месенджера, сторінка сама знайде коди. Можна також завантажити файли `.tank.json`.
2. Позначте галочками, хто бере участь. Фільтр **Блоки / Python** розділяє ліги.
3. **Ключ турніру** — будь-яке слово чи число. Однаковий ключ дає однакові бої, тож результат можна перевірити й переглянути повторно. Змініть ключ, щоб переграти турнір з іншими стартовими позиціями.
4. Режими:
   - **⚔️ Бій** — бій усіх обраних на одному полі («королівська битва»). Є кнопка «На весь екран» для проектора.
   - **📊 Кругова система** — кожен проти кожного. Розраховується за секунди, будь-який матч можна переглянути.
   - **🏆 Плей-оф** — сітка на вибування, матчі до двох перемог. Посів береться з кругової системи, якщо її вже розраховано. Матч можна «▶ дивитись» на екрані або «⚡» порахувати миттєво.
5. **💾 Зберегти список** — резервна копія всіх учасників у файл, щоб відкрити на іншому комп'ютері.

## Правила гри (коротко)

- Поле 800×600, у кожного танка 100 енергії.
- **Постріл** силою 0.1–3 коштує стільки ж енергії. Влучання забирає `4×сила` (плюс бонус за сильний постріл) і повертає стрільцю `3×сила`.
- **Радар** дивиться туди ж, куди гармата. Коли він бачить ворога, спрацьовує подія `бачу_ворога`, і гармата «захоплює» ціль.
- **Удари:** об стіну — −0.5, таран — −0.6 обом.
- **Виснаження:** якщо 600 ходів ніхто не влучає, всі поступово втрачають енергію.
- **Ліміт часу** — 4500 ходів. Після нього перемагає той, у кого більше енергії.
- **Очки:** шкода + 50 за кожного вибулого суперника, поки ти живий, + бонус останньому, хто вижив.

## Мова програмування

Підтримується шкільна підмножина Python: змінні, `if/elif/else`, `while`, `for … in range(…)`, функції `def`, `global`, списки, f-рядки, модулі `math` і `random`. Помилки пояснюються українською, а для описок пропонується правильне слово.

Нескінченний цикл без команд танк не «вішає»: виконання автоматично розбивається на ходи.

Події:

```python
def на_старті(): ...        # головна програма
def бачу_ворога(): ...       # радар побачив ворога
def влучили_в_мене(): ...    # у танк влучила куля
def вдарився_в_стіну(): ...  # вперся в стіну
```

Повний список команд — у вкладці «❓ Довідка» Майстерні.

## Файли

| Файл | Що всередині |
|---|---|
| `index.html` | Майстерня (учні) |
| `arena.html` | Арена (вчитель) |
| `engine.js` | Спільний рушій: транслятор Python, фізика бою, малювання, кодування ботів, вбудовані боти |
| `blocks.js` | Блоки Blockly українською і перетворення блоків на Python |
| `style.css` | Спільний стиль |

Blockly підвантажується з CDN jsdelivr, тому Майстерні потрібен інтернет. Арена працює й без нього.
